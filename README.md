# THO AU
AU Terminology FHIR Implementation Guide

## Building

This IG is authored with [FSH](https://fshschool.org/) and built with SUSHI and the HL7 FHIR IG Publisher, using the HL7 Australia template (`hl7.au.fhir.template`).

```bash
./_updatePublisher.sh   # download the IG Publisher
./_genonce.sh           # run SUSHI + IG Publisher; output in ./output
```
